# Roadmap

Soundscapy is under active development as we add features and refine the API. Shipped work is recorded in the [changelog](https://drandrewmitchell.com/Soundscapy/changelog.html); this page lists what is still ahead.

## Ongoing

- Bug fixes and API refinements as issues are reported.

## Near Term

- Better methods for cleaning datasets, including robust outlier exclusion and imputation.
- Restore the audio analysis guide (`Binaural`, `AudioAnalysis`, calibration and batch processing) and the "why distributions, not means" rationale, both lost when the docs moved to Great Docs ([#162](https://github.com/MitchellAcoustics/Soundscapy/issues/162)).

## Long Term

- Integrate the predictive modelling results from the SSID team's research to enable a single pipeline from recording → psychoacoustics → predicted soundscape perception. This is very much a pie-in-the-sky plan, and may not be possible.

Have an idea or a need that isn't listed? Please [open an issue](https://github.com/MitchellAcoustics/Soundscapy/issues) or see the [contributing guide](https://github.com/MitchellAcoustics/Soundscapy/blob/dev/CONTRIBUTING.md).
