# soundscapy

soundscapy is an open-source Python package for soundscape engineering. It analyses
soundscape surveys following ISO 12913, computes psychoacoustic metrics from calibrated
recordings, predicts how a soundscape will be perceived, and scores and designs
soundscapes with the Soundscape Perception Index (SPI). It is built to be used as a
library, in teaching material, and as the engine of tools for acoustic engineers,
architects and urban designers.

> This is the `soundscapy-rewrite` branch, a from-scratch rewrite that will become
> soundscapy 1.0. It is under active development and its API is not yet stable. The
> previous package continues on `main`.

## Install

```bash
uv add 'soundscapy==1.0.0.dev1'
```

The [quick-start page](https://github.com/MitchellAcoustics/Soundscapy/blob/soundscapy-rewrite/docs/user_guide/01-install.qmd)
installs uv, creates a project with soundscapy and JupyterLab, and draws a first plot, on
Windows, macOS and Linux.
