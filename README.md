# soundscapy (rewrite)

This branch (`soundscapy-rewrite`) is a from-scratch rewrite of soundscapy, an open-source
Python package for soundscape survey analysis, psychoacoustic analysis, predictive
modelling of soundscape perception, and scoring and design with the Soundscape
Perception Index (SPI) framework.

The code has been cleared out deliberately. The planning documents that drive the
rewrite live in `design/`:

- `design/PRD.md`: product requirements.
- `design/greenfield_architecture_plan.md`: architecture plan, out of date until it is
  rewritten from the PRD.

Development of the previous package continues on `main`.
